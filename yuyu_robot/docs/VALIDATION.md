# 验证记录

日期：2026-11-09。环境为独立 Ubuntu 22.04 / ROS 2 Humble 测试容器，Gazebo Classic 11.10.2，Nav2 1.1.20。图形测试使用 Xvfb 与软件 OpenGL；没有连接你的 VMware 或改动旧 Melodic 项目。

| 验证内容 | 结果 |
|---|---|
| colcon 编译与资源安装 | 3 个包通过 |
| xacro 展开与 Gazebo SDF 转换 | 通过；转换后的屏幕 visual 中保留 video 插件 |
| 规则/几何/绘图 | 8 项单元测试通过 |
| 默认启动组合 | Gazebo、RViz、键盘窗口、控制器、SLAM、Nav2 和功能节点均启动 |
| 图像与传感器 | 640×480 相机、360 点激光、四路下视、前后低位测距收到实际数据 |
| 表情与文字 | 六种 RGB 图像不同；中文显示后 3 秒清除 |
| 运动控制 | 正向指令方向正确；1 cm/s 测试实际反馈约 1 cm/s；0.3 rad/s 转向指令稳定后约 0.29 rad/s |
| 速度仲裁 | /cmd_vel 发布者只有 velocity_mux；键盘空闲零速度不阻塞导航 |
| 最终启动冒烟测试 | 里程计与 Gazebo 真值均前进约 0.0497 m；输入超时后停车 |
| “回去”导航 | NavigateToPose 返回成功，map 中目标误差约 9 mm |
| “过来”导航 | NavigateToPose 返回成功，map 中目标误差约 4 mm |
| 完整心形舞 | 60 个航点加闭合点共 61 点，map 中闭合误差约 5.7 mm；完成停车 |
| 真实前桌沿落差恢复 | 把模型放到 x=0.455 m；实际下视触发，后退至约 x=0.3909 m，转向约 89.3° 后停车 |
| 语音引擎 | espeak 中文离线 WAV 合成成功，22050 Hz、36664 帧 |

完整动作测试期间键盘窗口保持打开；舞蹈后半段同时运行 Gazebo 与 RViz。最后一次重新启动又检查了三窗口组合、传感器、图像和实际运动。

这些是当前测试环境的结果，不是对所有场景和虚拟机性能的保证。仍需在你的新虚拟机中验收：实际扬声器播放、VMware 图形驱动与流畅度、四个方向及角落的桌沿、改变物品/尺寸后的防护与路径。

心形舞会根据空间缩小，当前低速轨迹约需几分钟。这里的闭合误差来自 map TF，不是外部测量系统的轨迹 RMS。导航也在 map 中验收；轮式 odom 在转向时可能因打滑发生偏移。

RViz 的动态表情显示在 Face 面板，Gazebo 模型脸上使用 video 贴图。正常运行时无需手动启动各功能节点。

验收后只为遮住轮子增加了无碰撞的短腿外罩，动力学和接触几何保持上述测试配置；外观资源重新执行模型转换与图形检查。
